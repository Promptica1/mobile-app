# Юридические документы

- `offer.md`, `privacy.md` — русские тексты (оригинал, всегда есть).
- `offer.en.md`, `privacy.en.md` — английские версии. Файлы созданы пустыми: пока они пусты,
  англоязычным пользователям показывается русский текст с пометкой «доступно только на русском».
  Как только юрист проверит перевод — вставьте текст в файл, и он начнёт показываться сам.
- Другой язык: `offer.<код>.md`, `privacy.<код>.md` (например `offer.de.md`).
- Разметка: пустая строка — новый абзац, `# ` / `## ` — заголовки, `- ` — пункт списка, `**жирный**`.
- У каждого перевода своя «редакция» (отпечаток текста): при согласии записывается редакция
  того языка, который пользователь реально видел.
