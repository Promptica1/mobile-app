# Digital Wardrobe

Next.js (App Router) + TypeScript + Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Деплой на Vercel

Импортируйте репозиторий на vercel.com → New Project. Vercel сам определит Next.js — дополнительная настройка не нужна.
